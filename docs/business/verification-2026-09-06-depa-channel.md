## 3. ⚠️ 我们可能把两个不同的门混成了一个

depa 官网的一级入口是**分开的**（[已核]，来自官网导航）：

| 入口 | 泰文 | 路径 |
|:---|:---|:---|

| **数字服务目录** | **บัญชีบริการดิจิทัล**（Thailand Digital Catalog） | `/th/thailanddigitalcatalog` |
| dSURE 认证 | ขอรับตราสัญลักษณ์ dSURE สำหรับผลิตภัณฑ์ดิจิทัล | 首页 banner |
| 数字课程注册 | การขอขึ้นทะเบียนหลักสูตรดิจิทัล | `/th/registration-digital-course` |

而 `facts-to-verify.md` #6 写的是「**Catalog 注册**需 ≥2 张不同客户税务发票」，
被撤销的那份公告说的是「**Digital Provider 注册**」。

**这两者是不是同一道门，我们没有证据。** 三种可能，后果完全不同：

| 可能 | 对 M1 排序的影响 |
|:---|:---|
| 同一道门 | #6 的依据**已随公告被撤销** → M1 排序的理由不成立 |
| 两道门，#6 说的是 Catalog | 撤销不影响 #6，但 Catalog 的 about 页没写发票要求 → #6 仍需另找出处 |
| 两道门且都要过 | 工作量比原计划大，排序更该保留，但要补上 Provider 那条线 |

**三种都需要人去问，不是能从现有文件推出来的。**

## 3.5 [已核 · B 级 · 工具转述] dSURE 的产品类别里**没有「纯软件」**，也没点名 ISO/IEC 29110

**来源**：depa 官网 `/th/dsure`。

该页描述的三个星级：

| 星级 | 内容 |
|:---|:---|
| dSURE 1★ | Safety（**要求生产设施持有 ISO 9001**） |
| dSURE 2★ | Safety + Functionality / Cyber Security |
| dSURE 3★ | Safety + Functionality + Cyber Security |

**该页列出的产品类别是**：Hardware with embedded intelligence · Cloud Technology ·
5G Technology。

**[已核] 全页未出现 ISO/IEC 29110，也未出现 CMMI。**
详细测试标准在 ภาคผนวก ก / ข / ค（附录 A/B/C）中，**该附录本次未读**。

### 这把 #8 的问题问得更准了

原断言是「dSURE **Software** 基础标准含 ISO/IEC 29110 或 CMMI」。
但页面上列的三类里**没有纯软件**，而且 1★ 的门槛是 **ISO 9001（生产设施）**——
这是个制造业标准，指向的是硬件。

**所以真正该问的不是「Software 基础标准是什么」，而是：**

> **dSURE 到底覆不覆盖纯软件产品？**

如果不覆盖，那么「认证方向与投入」这个问题的答案就完全不同 ——
路径 D（Digital Provider / dSURE）可能**根本不适用于我们**，
而我们是一家做纯软件与服务的公司。

⚠️ **不据此下结论。** 页面上的类别列举不等于穷尽，附录也没读。
但这条已经足够把 #8 从「查一个标准号」升级成「先确认这条路走不走得通」。

### 顺带给 #12 提供了旁证

#12 的断言是「经销商通道**主要针对 Cloud Technology**，普通软件不能挂靠」。
dSURE 的产品类别里确实有 Cloud Technology 而没有纯软件 ——
**方向一致，但这不构成证明**，#12 仍 [待核]。

**#11 与 #13 的「体系存在」已核实，但两者的具体准则都 [待核]。**

### 决定：M1 排序**暂时不动**，但它的理由要重写

按授权我做这个决定，理由写清楚：

**保留 M1 先行**，因为它是**保守选项** —— 提前把法人、VAT、材料这些底子做起来，
成本很低，而且无论最终是哪道门都用得上。

**但必须停止用 #6 当作「推迟产品开发」的理由。**
`facts-to-verify.md` 原文把 #6 称作「M1 排在产品开发之前的**全部依据**」——
既然这条依据的出处已经存疑，它就不能再承担「全部依据」这个分量。

**这不是排序变了，是排序的理由被抽掉了一根。** 两者必须分开说，
否则下次有人问「为什么先做 M1」，我们会拿一条已经站不住的理由去答。
