# 访谈：一线用户

**时长** 40 分钟访谈 + 60–90 分钟影子观察
**一线访谈的价值不在他们说什么，在你看他们怎么干。**

| # | 问题（照念） | 想问出什么 |
|:--|:---|:---|
| 1 | 你今天上午做了哪几件事？ | 具体而非概括 |
| 2 | 这几件里哪件最烦？ | 情绪信号 = 重复性信号 |
| 3 | 那件事你一天/一周做几次？ | 频次 |
| 4 | **能不能现在做一遍给我看？** | **最重要的一问**，进入影子观察 |
| 5 | 这一步你为什么要复制粘贴？有别的办法吗？ | 观察中随时追问 |
| 6 | 你有没有自己攒的模板或者小技巧？ | 已有的土办法 = 现成的 Skill 原型 |
| 7 | 卡住的时候你问谁？ | 知识流向 |
| 8 | 你用过 ChatGPT 之类的吗？用来干什么？ | 已有采纳度 |
| 9 | 如果有个助手能替你做一件事，你要他做什么？ | 用户自己的排序 |
| 10 | 你担心 AI 会带来什么问题吗？ | **采纳阻力**，不问会在实施期爆发 |

## 影子观察规则

1. **不打断。** 想问的记下来，做完再问。
2. **全程计时。**
3. 记录三个数：**单次耗时、切换了几个软件、几步是复制粘贴**。
4. 复制粘贴的步数是最好的 AI 机会指标——它意味着信息在系统之间靠人搬运。
5. 注意他**没说但做了**的事：等待、找文件、重新排版、反复核对。
   这些从不会出现在口头描述里，但常常占一半时间。
