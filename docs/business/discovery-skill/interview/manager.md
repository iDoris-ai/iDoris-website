# 访谈：部门负责人 / 中层

**时长** 60–75 分钟（含 15 分钟缓冲，不要背靠背排）
**每场结束立刻**在 `02-pain-inventory.md` 补 3–5 行，不要攒着

| # | 问题（照念） | 想问出什么 |
|:--|:---|:---|
| 1 | 请带我走一遍你们部门一周典型的工作流程 | 工作流地图的原料 |
| 2 | 这个流程里哪一步最容易卡住？ | 瓶颈 |
| 3 | 你们部门一个月要产出多少份 [报告/报价/方案]？ | **频次，年化工时的分母** |
| 4 | 做一份大概要多久？谁做？ | **单次耗时 + 人数** |
| 5 | 做的时候信息从哪里来？要开几个软件？ | 信息散落程度 |
| 6 | 有没有哪一步是「把 A 系统的东西复制到 B 系统」？ | **最强的 AI 机会指标** |
| 7 | 你们怎么保证质量？谁复核？ | 决定能不能自动放行 |
| 8 | 出错的时候通常错在哪一步？ | Risk 轴的原料 |
| 9 | 新人上手这个岗位要多久？卡在什么地方？ | 知识沉淀的机会 |
| 10 | 有没有什么事是只有某一个人会做的？ | 单点依赖 |
| 11 | 你们跟客户/其他部门主要用什么沟通？ | LINE？决定要不要做 LINE Agent |
| 12 | 需要泰英互译的场合多吗？谁翻？ | 翻译是泰国市场最容易见效的切口 |
| 13 | 如果给你多一个人，你会让他干什么？ | **最想卸掉的活** |
| 14 | 你觉得哪一步机器能干？ | **必须放最后**，否则会带偏前面所有回答 |

## 纪律

第 14 题放最后是硬规矩。先问它，对方会开始揣摩你想听什么，
前面 13 题的事实性回答就全被污染了。
