# 痛点清单模板

**每行必须有全部列，缺列的行不算数。** 没有数字的痛点在提案阶段一定会被砍掉。

| # | 痛点 | 谁 | 频次/年 | 单次耗时(h) | 涉及人数 | 年化工时 | 年化成本(THB) | 数据来源 |
|:--|:---|:---|---:|---:|---:|---:|---:|:---|
| 1 | | | | | | | | 访谈/实测 |

## 计算公式

```
年化工时 = 单次耗时(小时) × 频次(次/年) × 涉及人数
年化成本 = 年化工时 × 该角色时薪
```

## 频次怎么问

**不要问「多久一次」**，问具体的：

- 「上周做了几次？」→ ×52
- 「上个月做了几次？」→ ×12
- 「今年到现在做了几次？」→ 按已过月份折算

## 时薪怎么取

不要问工资。问「这个岗位招人大概什么价位」，除以 `12 × 22 × 8`。

算不出就用一个明确的假设值，**并在交付物里写明这是假设**。

## 「单次耗时」的两个来源

| 来源 | 可信度 | 标注 |
|:---|:---|:---|
| 影子观察实测 | 高 | `实测` |
| 受访者自述 | 低（人普遍低估重复工作耗时） | `自述` |

**至少 Top 3 用例涉及的痛点必须有实测数据。**
