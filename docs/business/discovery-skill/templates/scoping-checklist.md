# 定范围检查表（进场前）

## 3 天还是 5 天

逐条勾，**满足 2 条及以上就报 5 天**。拿不准也报 5 天——
3 天做不完的后果是交付物注水，比报贵了严重得多。

- [ ] 跨 2 个以上部门
- [ ] 没有成文流程，全靠人的经验
- [ ] 人数 ≥ 50
- [ ] 需要接现有系统（CRM / ERP / 数据库）
- [ ] 泰语为主且文档全泰文

## 进场前 48 小时必须拿到

- [ ] 组织架构图，或口头说清有哪些部门、各多少人
- [ ] **3–5 个受访者名单与时段，含至少 1 个决策层** ← 硬门槛
- [ ] 日常软件清单
- [ ] 3 份真实工作文档样例（脱敏）：报价单、报告、对客沟通各一
- [ ] 一句话：他们自己觉得最浪费时间的是什么

> **拿不到「至少一个决策层」就不要进场，宁可推迟一周。**
> 没有老板参与的 Discovery 一定会变成一群中层陪你聊天，最后没人拍板。

## 现场第一小时必须确认

- [ ] 录音同意（口头即可，但要记进 `00-engagement-log.md`）
- [ ] 数据边界：哪些不能看、哪些不能拷贝
- [ ] 交付会时间与参加人（**必须含决策层**）
