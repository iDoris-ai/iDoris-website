# AI Readiness 五维评分表

**不要凭感觉打分。** 每一分都有可观察的判据。打完跑 `scripts/score.py readiness`。

| 维度 | 1 分 | 3 分 | 5 分 | 本次 |
|:---|:---|:---|:---|:---:|
| **数据可得性** `data` | 数据只在人脑子里或纸上 | 有电子文档但散落各处 | 有结构化系统且可导出/有 API | |
| **流程标准化** `process` | 每个人做法都不一样 | 有惯例但没成文 | 有成文 SOP 且真的在执行 | |
| **工具基础** `tooling` | 只有 Excel 和聊天软件 | 有几个业务系统但不互通 | 有集成的系统栈，有 IT 能力 | |
| **人员意愿** `willingness` | 明确抵触，怕被替代 | 观望，个别人自己在用 | 主动在找工具，已有人在用 AI | |
| **治理准备** `governance` | 没想过数据合规 | 知道有风险但没规矩 | 有明文的数据分级与权限制度 | |

**2 分 / 4 分**：介于相邻两档之间时给。不要为了好看往上凑。

## 总分解读

| 总分 | 结论 |
|:---|:---|
| ≤ 10 | **不建议现在做 Implementation。** 先做 Enablement，或直接建议暂缓 |
| 11–17 | 从 **L1 Skill Pack** 起步，不要一上来做集成 |
| ≥ 18 | 可考虑 **L2 Agent / L3 集成**，但第一个用例仍选一周内见效的 |

> **「建议他们别做」是一个合法结论，照实写进交付物。**
> 这是可信度的来源，不是失败。
