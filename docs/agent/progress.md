## 教训留档

**2026-09-05：一致性证明不了正确性。**

这条教训已写进 `tasks.md` 的 T3.2.2（待核事实清单），
并成为本轮所有调研类交付物的强制格式要求：
**每个影响决策的事实要么 [已核] 要么 [待核]，没有第三种。**
